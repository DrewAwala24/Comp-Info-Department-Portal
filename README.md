# University Department Portal

A robust web application built with Java Spring Boot and PostgreSQL designed to streamline academic administration, course management, and scheduling.

## Key Features Built So Far
- **Data Persistence & Schema:** Relational database integration using Spring Data JPA and PostgreSQL.
- **Domain Models:** Entities established for `User` (Role-Based Access), `Course`, and `Timetable`.
- **Repository Architecture:** Abstraction layer implementing derived database queries.
- **Service Layer:** Business logic handling data validation, user operations, course scheduling, and timetable retrieval.

## Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** PostgreSQL (managed via JetBrains DataGrip / Hibernate)
- **Build Tool:** Maven
